# ハラールマップ（試作）

現在地から近い順に、ハラール対応のお店を探せる一覧です。
地図と経路はGoogleマップで開きます（地図描画は自前で持ちません）。

**デモ:** https://2026justeco-crypto.github.io/halal-map/

> **試作段階です。** 意見をいただくために限定的に公開しています。
> 掲載件数はまだ少なく、内容の確認も途中です。実際のお店選びの判断にはお使いにならないでください。

## 考え方

ハラールは「間違っていました」が信仰上の実害になります。
豚由来・アルコールの混入は、利用者にとって取り返しがつきません。
そのため次を設計の前提にしています。

- **認証の区分を必ず分けて表示する** — 「認証済み」「自己申告」「一部対応（ムスリムフレンドリー）」を
  色とラベルで区別し、その説明を一覧より**前**に置く（後ろに置くと読まれないため）。
- **出典を1件ずつ示す** — 各カードに認証団体名と出典リンクを付ける。
- **最終確認はお店へ** — 原材料・調理器具・仕入れ先は予告なく変わり、認証にも有効期限がある。
  このサイトは食べられるかどうかを保証しない、と明記する。
- **「認証済み」を自己申告で通さない** — 掲載依頼で認証済みを選ぶ場合は認証団体名・番号を伺い、
  団体の公表情報で裏が取れたものだけをその区分で掲載する。
- **精度の低い情報を、精度の高い情報と同じ顔で出さない** — 下記参照。

## データ

出どころは2つあり、**確からしさが違うので区分を分けて表示**しています。

### ①「認証済み」— 認証団体の公開情報

- 出典：[一般社団法人ジャパン・ハラール・ファンデーション](https://japanhalal.or.jp/shop) の公開「認証実績」
- ★**このページは店舗ディレクトリではなく、事業者向けの認証実績一覧**です。そのため店名が途中で切れる、
  事業者名が混ざるといった弱点があり、画面上でもそう説明しています。
- 収録は**6都府県・51件**にとどまります。これだけでは「近くの店を探す」用途に足りないため②を足しました。

### ②「地図データ」— OpenStreetMap

- 出典：OpenStreetMap（`diet:halal` / `halal` / `cuisine=halal` のタグが付いた日本国内の地点）
- ★**書き込んだのは店でも認証団体でもなく、地図を編集した誰か**です。審査も店への確認も経ていません。
  だから `certified` / `self` / `friendly` のどれにも入れず、**`osm`（地図データ）という区分を新設**して分けています。
  「誰が言っているか」で区分を切るのがこのサイトの安全設計なので、そこは崩しません。
- 「全てハラール（`only`）」と「ハラールのものを出している（`yes`）」は意味が違うので、**カードごとに書き分け**ています。
- コンビニ・スーパーも含まれます。「ハラールの商品を置いている」という意味で書かれたもので、
  店全体がハラールという意味ではありません。画面上にもそう書いています。
- 名前の無い地点は「店を探す」用途に使えないので除外しています（件数はビルド時に表示）。
- 認証済みの店と重複するもの（同名、または80m以内で名前が部分一致）は認証済み側を残します。
  誤って消すほうが害が大きいので、条件は厳しめにしてあります。

**ライセンス:** 地図データ由来の部分は © OpenStreetMap contributors / [ODbL 1.0](https://www.openstreetmap.org/copyright)。
画面のフッターと `data/stores.json` の `sources` に表示しています。

### 共通

- 取得するのは事実情報のみ（店名・住所・電話番号・ジャンル・営業時間）。紹介文などは取り込みません。
- **公式サイトへのリンクはどちらの出どころでも出していません。**
  認証実績のURLは事業者のサイトであることが多く、実測で4件に1件がリンク切れでした。
  代わりに「店名で調べる」を用意しています。
- 緯度経度は[国土地理院の住所検索API](https://msearch.gsi.go.jp/)で住所から求めています（無償・APIキー不要）。
- **位置の細かさを `geo_precision` で区別しています。**
  番地・丁目まで一致したものだけ距離と徒歩分を表示し、区や都道府県の中心にしか落ちていないものは
  「約」を付けて「位置はおおよそです」と明記し、地図も座標ではなく住所文字列で開きます。
- ジオコーディングに失敗した店は**消さずに残してフラグを立てます**（載っていない＝無い、と誤解されるため）。

## Googleマップとの連携

`https://www.google.com/maps/search/?api=1&query=...` という公式のUniversal Linkを使っています。
iOS・Androidとも、アプリが入っていればアプリ、なければブラウザで開きます。
`comgooglemaps://` のようなアプリ専用スキームでの端末判定はしていません
（未インストール端末でエラーになり、OSの仕様変更でも壊れるため）。

## プライバシー

位置情報はブラウザ内でのみ利用し、サーバーへ送信・保存していません。

## 動かす

```
node serve.js     # → http://localhost:8788
```

位置情報はブラウザの仕様上、https か localhost でないと使えません。

データを作り直す場合：

```
node tools/scrape-jhf.js     # 認証団体の出典ページから取得
node tools/fetch-osm.js      # OpenStreetMap から halal タグの地点を取得（Overpass API）
node tools/build-stores.js   # 整形＋ジオコーディング＋2つの出どころを統合
```

`build-stores.js` は `data/raw-osm.json` が無ければ OSM 分を黙って飛ばします。
緯度経度からの都道府県・市区町村の逆引きにも国土地理院のAPIを使っています（無償・キー不要）。

掲載依頼フォームを有効にする手順は [SETUP.md](SETUP.md) を参照してください。
