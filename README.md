# ハラールマップ（試作）

現在地から近い順に、ハラール対応のお店を探せる一覧です。
地図と経路はGoogleマップで開きます（地図描画は自前で持ちません）。

**デモ:** https://2026justeco-crypto.github.io/halal-map/

> **試作段階です。** 意見をいただくために限定的に公開しています。
> 掲載件数はまだ少なく、内容の確認も途中です。実際のお店選びの判断にはお使いにならないでください。

## 考え方

ハラールは「間違っていました」が信仰上の実害になります。
豚由来・アルコールの混入は、利用者にとって取り返しがつきません。
そのため次を設計の前提にしています。

- **認証の区分を必ず分けて表示する** — 「認証済み」「自己申告」「一部対応（ムスリムフレンドリー）」を
  色とラベルで区別し、その説明を一覧より**前**に置く（後ろに置くと読まれないため）。
- **出典を1件ずつ示す** — 各カードに認証団体名と出典リンクを付ける。
- **最終確認はお店へ** — 原材料・調理器具・仕入れ先は予告なく変わり、認証にも有効期限がある。
  このサイトは食べられるかどうかを保証しない、と明記する。
- **「認証済み」を自己申告で通さない** — 掲載依頼で認証済みを選ぶ場合は認証団体名・番号を伺い、
  団体の公表情報で裏が取れたものだけをその区分で掲載する。
- **精度の低い情報を、精度の高い情報と同じ顔で出さない** — 下記参照。

## データ

- 出典：[一般社団法人ジャパン・ハラール・ファンデーション](https://japanhalal.or.jp/shop) の公開「認証実績」
- 取得するのは事実情報のみ（店名・住所・電話番号・ジャンル・営業時間・公式サイト）。紹介文などは取り込みません。
- 緯度経度は[国土地理院の住所検索API](https://msearch.gsi.go.jp/)で住所から求めています（無償・APIキー不要）。
- **位置の細かさを `geo_precision` で区別しています。**
  番地・丁目まで一致したものだけ距離と徒歩分を表示し、区や都道府県の中心にしか落ちていないものは
  「約」を付けて「位置はおおよそです」と明記し、地図も座標ではなく住所文字列で開きます。
- ジオコーディングに失敗した店は**消さずに残してフラグを立てます**（載っていない＝無い、と誤解されるため）。

## Googleマップとの連携

`https://www.google.com/maps/search/?api=1&query=...` という公式のUniversal Linkを使っています。
iOS・Androidとも、アプリが入っていればアプリ、なければブラウザで開きます。
`comgooglemaps://` のようなアプリ専用スキームでの端末判定はしていません
（未インストール端末でエラーになり、OSの仕様変更でも壊れるため）。

## プライバシー

位置情報はブラウザ内でのみ利用し、サーバーへ送信・保存していません。

## 動かす

```
node serve.js     # → http://localhost:8788
```

位置情報はブラウザの仕様上、https か localhost でないと使えません。

データを作り直す場合：

```
node tools/scrape-jhf.js     # 出典ページから取得
node tools/build-stores.js   # 整形＋ジオコーディング
```

掲載依頼フォームを有効にする手順は [SETUP.md](SETUP.md) を参照してください。
